# Migration 0.3.0 — the digest verb, and the update path

**Takes a vault from 0.2.0 to 0.3.0.** Small: 5 to 15 minutes.

Read [../UPDATES.md](../UPDATES.md) first. It resolves the vault, recovers this owner's placeholder values,
and holds the safety contract. This document assumes all of that already happened, and that you have the
kit's `seed-vault/` available at `<kit>/seed-vault/`.

---

## What it adds

A fifth knowledge verb. **`/digest`** turns the substantive content of a session into a spoken-word script
plus a pre-rendered MP3, written to a new `digests/` section of the vault, for listening to later — on a
drive, on a walk, away from a screen.

A digest is an **interface, never a record**. The wiki holds what is true. A digest holds one explanation of
it, shaped for ears, that ages out. So `/process` is now explicitly forbidden from reading `digests/`, and
`/maintain` gains a retention move that sends digests older than 60 days to `digests/heard/`. Nothing is
deleted.

This version also adds the **update path itself**: `.claude/VERSION.md`, the `brain-update` skill, and the
`/brain-update` command, so the next update is one command instead of this document.

**It is additive.** It creates new files and makes six anchored edits. It touches no wiki page, no note, and
no source.

### When an anchor is missing

**Stop that edit. Do not improvise a location.** Show the owner the section as their file actually has it,
say what you meant to insert and where, and let them place it or decline it.

A missing anchor almost always means they rewrote that section. Their wording stays. Record the skipped edit
in `.claude/VERSION.md` and in `wiki/_log.md`.

**Edits 1, 2, and 5 are the load-bearing ones.** Without them the vault gains a `digests/` folder that
`/process` may compile into the wiki, which is exactly the failure this design exists to prevent. If any of
those three cannot be applied, say so in the strongest terms and get the owner to place it by hand before
they use `/digest`.

## 4. Dependencies the owner installs

The renderer needs **edge-tts**. It is free, needs no API key, and needs a network connection at render
time.

```bash
pip install edge-tts
```

**FFmpeg is optional.** `render-digest.py` calls `ffprobe` to measure the real duration of the MP3. Without
it the renderer still works and reports `"seconds": null`, and the skill then records the runtime as unknown
rather than guessing one.

**State these and let the owner run them. Do not install software on their machine.**

Without `edge-tts`, `/digest` still writes the script and sets `audio: none`. The markdown is the artifact.
The MP3 is a convenience.

## What this migration must not touch

## Rollback

Delete the new files and folders: `digests/`, `.claude/skills/audio-digest/`,
`.claude/skills/brain-update/`, `.claude/commands/digest.md`, `.claude/commands/brain-update.md`,
`.claude/scripts/render-digest.py`, `.claude/VERSION.md`.

Restore `SCHEMA.md` and any other edited file from its `.pre-0.3.0` backup.

Re-run the copy-install so `~/.claude/` matches the vault again, and delete
`~/.claude/skills/audio-digest/`, `~/.claude/skills/brain-update/`, `~/.claude/commands/digest.md`, and
`~/.claude/commands/brain-update.md` by hand — the install copies files in, and it never deletes.

Then append a `maintenance` line to `wiki/_log.md` saying the update was rolled back, and why.
